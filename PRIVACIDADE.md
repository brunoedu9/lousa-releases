# Política de privacidade do Lousa

*Última atualização: novembro de 2026*

O Lousa é um editor de diagramas para Windows. Esta política explica quais dados ele usa e onde ficam.

## Seus documentos e preferências

Os diagramas que você cria ficam **onde você os salvar** (arquivos `.lousa`). As preferências do aplicativo (tema, posição da janela, painéis) ficam em `%LOCALAPPDATA%\Lousa`. O Lousa **não tem servidores**, não exige conta e **não envia seus documentos** para os desenvolvedores nem para terceiros. Não há telemetria.

## Verificação de atualizações

Por padrão, no máximo uma vez a cada 24 horas, o Lousa consulta a página pública de releases deste repositório (`api.github.com`, endereço `releases/latest`) para saber se existe versão nova.

- **O que é enviado:** apenas uma requisição anônima com o nome genérico do cliente (`Lousa-Updater`). Nenhum documento, nome, identificador ou informação do seu computador é incluído. Como em qualquer acesso pela internet, o GitHub pode registrar o seu endereço IP, conforme a [política de privacidade do GitHub](https://docs.github.com/pt/site-policy/privacy-policies/github-general-privacy-statement).
- **O que acontece depois:** se houver versão nova, o Lousa só mostra um aviso. O download e a instalação só ocorrem quando você clica, e o instalador é verificado por SHA-256.
- **Como desativar:** **Ajuda › Verificar atualizações automaticamente**. Com a opção desmarcada, o Lousa não faz nenhuma conexão de rede por conta própria.
