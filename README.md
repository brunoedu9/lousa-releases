# Lousa

Editor de diagramas para Windows: fluxogramas, redes, arquitetura e organogramas, tudo offline, com os documentos guardados no seu próprio computador.

## Baixar

Vá em **[Releases › mais recente](https://github.com/brunoedu9/lousa-releases/releases/latest)** e baixe:

- **`Lousa-Setup-<versão>.exe`** — instalador (recomendado);
- **`Lousa-<versão>-portatil.exe`** — versão portátil, sem instalação.

Depois de instalado, o Lousa verifica por conta própria se há versão nova (uma consulta por dia, desativável em **Ajuda › Verificar atualizações automaticamente**) e avisa na barra inferior. A atualização só é instalada quando você clica, e o instalador é conferido por SHA-256 antes de ser executado.

Se o Windows mostrar **"O Windows protegeu o computador"**, clique em **Mais informações › Executar assim mesmo**. O aviso aparece porque o instalador ainda não tem assinatura digital.
